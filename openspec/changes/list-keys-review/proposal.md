# list-keys-review (PR #79 리뷰 반영, 이슈 #78)

## Why

PR #79 리뷰 2축에서 나온 것:

- 꾸미기 보정이 문서 전체 최상위 블록을 보고 있었다. 다른 곳에 같은 꾸미기 목록이 있으면 빠져나온 문단이 꾸미기를 잃었다.
- 항목 맨 앞 Backspace로 문단이 된 뒤 다시 Backspace를 누르면, 기본 joinBackward가 문단을 목록 항목으로 되감싸 내어쓰기와 핑퐁이 된다.
- 목록이 둘로 갈릴 때 글꼴까지 앞 조각에만 남기면 뒤 조각의 글씨체가 갑자기 바뀌어 보인다.

## What Changes

- 꾸미기 보정 범위를 원래 목록이 차지하던 자리로 좁힌다. 보정은 `dropDuplicatedDecoration` · `restoreLostDecoration` 둘로 나눈다.
- 목록이 갈리면 글꼴은 두 조각 모두, 움직임 · 스티커는 앞 조각에만 남긴다.
- 목록 바로 뒤 최상위 문단 맨 앞 Backspace는 앞 목록 마지막 항목 끝에 글자를 합친다(Notion과 같다).
- 스티커 비교는 `sameStickers`를 쓴다.

## Impact

- 하지 않는 것: 번호 목록 시작 번호(start). 가운데를 빼면 뒤 조각 번호가 1부터 다시 시작한다 — 후속 이슈.
