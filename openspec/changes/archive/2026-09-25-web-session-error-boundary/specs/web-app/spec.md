## ADDED Requirements

### Requirement: 화면이 첫 불러오기에서 받은 401은 오류 화면이 아니라 로그인 화면으로 보낸다

web은 SHALL 로그인이 필요한 화면이 첫 불러오기 실패로 `UnauthorizedError`를 던지면 오류 화면을 보이지 않고, 가드와 같이 `loginPathFor(current)`로 로그인 화면에 보낸다. 401이 아닌 오류는 지금처럼 오류 화면으로 간다.

#### Scenario: 세션이 끊긴 뒤 글 목록으로 가면 로그인 화면, 다시 로그인하면 글 목록(실브라우저)

- **WHEN** 로그인한 채 글 목록이 캐시에 없는 화면을 열고 쿠키를 지운 뒤 메뉴로 글 목록에 간다
- **THEN** 오류 화면이 아니라 로그인 화면이 뜨고, 다시 로그인하면 글 목록으로 돌아온다

#### Scenario: 세션이 끊긴 뒤 목록에서 글을 열면 편집 경로를 next로 기억한다(실브라우저)

- **WHEN** 로그인한 채 목록을 띄우고 쿠키를 지운 뒤 목록에서 글을 연다
- **THEN** `/login?next=%2Fposts%2F<slug>%2Fedit`로 가고, 다시 로그인하면 그 편집 화면으로 돌아온다

#### Scenario: 401이 아닌 실패는 오류 화면(실브라우저)

- **WHEN** 로그인한 채 글 목록 요청이 500으로 실패한다
- **THEN** 로그인 화면이 아니라 오류 화면 「화면을 그리지 못했어요」가 뜬다
