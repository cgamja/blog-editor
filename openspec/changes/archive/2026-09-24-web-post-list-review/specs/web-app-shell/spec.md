## ADDED Requirements

### Requirement: 로그아웃 요청이 실패하면 로그인된 채로 남는다

web은 SHALL 로그아웃 요청이 실패하면 지금 화면과 세션 캐시를 그대로 두고 로그아웃하지 못했다는 문장과 다시 시도를 보인다 — 쿠키가 아직 유효한데 로그인 화면으로 보내면 로그아웃됐다고 믿게 된다.

#### Scenario: 로그아웃 요청이 실패하면 목록에 남는다(실브라우저)

- **WHEN** 로그아웃 요청이 네트워크 오류로 실패한다
- **THEN** 글 목록에 그대로 있고 "로그아웃하지 못했어요"와 다시 시도가 보인다
