# web-post-list-review (PR #104 리뷰)

## Why

PR #104 리뷰 2축(blocker 없음)의 지적을 한 번에 반영한다. 로그아웃 요청이 실패해도 로그인 화면으로 가서 "로그아웃됐다"고 믿게 만드는 보안 구멍, 목록 응답을 확인 없이 형 변환하던 것, 뒤에서 다시 불러오기가 실패하면 목록이 오류 화면으로 바뀌던 것, 기능 사이 import를 막는 린트가 없던 것, 글자 크기 · 그림자가 토큰 밖에 있던 것.

## What Changes

- 로그아웃 요청이 실패하면 화면과 세션을 그대로 두고 "로그아웃하지 못했어요 · 다시 시도"를 보인다
- 목록 응답은 항목마다 필드 형을 확인하고 틀리면 몇 번째 항목의 어느 필드인지 말하는 오류를 던진다. 목록 한 줄 키가 계약(`api/openapi.json` PostList)과 같은지 테스트가 고정한다
- 첫 불러오기가 실패할 때만 오류 경계로 간다 — 뒤에서 다시 불러오기가 실패해도 보던 목록은 그대로
- 토큰 생성기: `font`의 px 값 → `--font-size-<이름>`, 새 `shadow` 그룹 → `--shadow-<이름>`(색은 `color-mix`로 색 토큰에서). 캔버스에만 있던 값(행 제목 16 · 포스트잇 17 · 로고 24 · 제목 34, 그림자 셋)을 tokens.json에 옮기고 출처를 design/map.md에
- eslint: `features/**`는 app도 다른 기능도 import하지 않는다
- 빈 목록일 때 머리의 세 동작을 숨긴다(두 번 보이지 않게), 768 이하에서 고친 날 열은 남긴다

## Impact

- 보호 파일 `eslint.config.mjs`(PR diff로 승인)
- 하지 않는 것: 계약 생성기(orval 등) — 응답 확인은 손으로 둔다
