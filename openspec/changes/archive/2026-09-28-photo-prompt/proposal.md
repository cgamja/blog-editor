# photo-prompt (이슈 #155)

## Why

ADR-029는 AI 이미지를 Codex CLI로 만들기로 했지만, ChatGPT 무료 플랜은 Codex 이미지 생성이 막혀 있고 사용자는 유료 계정이 없다. Claude는 사진 같은 이미지를 만들지 못한다. 사용자 결정(2026-09-28): 이미지는 사람이 Midjourney 등으로 만들고, AI는 무엇을 만들지 적어 둔다. 지금 사진 자리의 한국어 설명은 대체 글자(alt)로도 쓰여 이미지 도구용 영어 프롬프트를 겸할 수 없다.

## What Changes

- 사진 자리(`photoPlaceholder`)에 에디터 전용 `prompt`(영어 이미지 프롬프트, 한 문단 · 1000자 이내) 속성. 공개 문서(`publicDocOf`) · 공개 API · 렌더에 나가지 않는다.
- markdown: `:::photo` 안 둘째 문단이 `prompt:`로 시작하면 프롬프트다(직렬화 · 파싱 왕복).
- 사진을 채우면 프롬프트도 설명(brief)처럼 그림에 에디터 전용으로 남는다.
- 편집 화면 사진 자리: 프롬프트를 보이고 고칠 수 있게, 「프롬프트 복사」는 비율이 있으면 ` --ar W:H`를 붙여 클립보드로.
- `/blog-write` · 형식 가이드: 사진 자리마다 설명 + 영어 프롬프트(글 종류별 스타일)를 쓴다. Codex 생성 안내를 지운다. ADR-043(ADR-029 대체).

## Impact

- 새 의존성 없음. 문서 스키마에 선택 속성 하나(schemaVersion 규칙 확인). 공개 계약 그대로.
- 하지 않는 것: 이미지 생성 자체, 외부 이미지 서비스 연동.
