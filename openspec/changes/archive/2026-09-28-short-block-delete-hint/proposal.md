# short-block-delete-hint (이슈 #178)

## Why

지우기(빈 markdown)에서는 블록 전체 고르기를 끄면서 블록 전체와 같은 곳 목록까지 비웠다. 그래서 [소제목 '산책', 문단 '오늘 산책을 했다']에서 '산책'을 지우려 하면 "2곳 — 더 긴 글로 한 곳만 집는다"만 나온다. 소제목 글자 전체가 '산책'이라 더 긴 글로는 집을 수 없어, AI가 할 수 없는 안내만 받는다.

## What Changes

- content-convert `editDocRange`: 블록 전체와 같은 곳은 고르기 여부와 상관없이 계산하고, 지우기에서 그런 곳이 있으면 "블록 전체" 안내 줄을 넣는다(고르지는 않는다).
- 안내 줄에 "이웃 블록의 지시어도 함께 적는다"를 더한다 — 이웃까지 다시 쓰면 font · align이 말없이 초기화되기 때문.
- 강제 줄바꿈 재시도 경로에서 지우기가 넘어가는지 테스트로 고정.

## Impact

- 새 의존성 없음. 문서 스키마 · 공개 계약 그대로. 실패 메시지 문구만 늘어난다.
- 하지 않는 것: 지우기에서 블록 전체 고르기를 켜기(adr-038 — 지우기는 오판 비용이 커서 끈다).
