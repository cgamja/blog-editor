# mcp-guide-edit (이슈 #143)

## Why

반복되는 불만("이런 말투 싫어", "문단은 짧게")을 CLI에서 바로 글쓰기 가이드에 남기고 싶다. 지금 워크스페이스 글쓰기 가이드는 에디터 설정 화면에서만 고칠 수 있다. 글 종류별 틀(앱 소개 · 정보 전달 등)도 가이드에 두어 AI가 글 종류마다 따르게 하고 싶다.

## What Changes

- MCP 도구 `update_writing_guide` — 워크스페이스 글쓰기 가이드 전체를 새 글로 바꾸고, 바뀐 가이드를 응답으로 돌려준다. 형식 가이드(`guide/format.md`)는 고치지 못한다. 설정 저장과 같은 크기 상한.
- 도구 설명 · 형식 가이드에 "### 글 종류별 틀" 구역 약속을 적는다: 워크스페이스 가이드("## 이 블로그의 글쓰기 가이드" 아래부터 끝)에 이 구역이 있으면 글 종류(#### 앱 소개 등)별 틀을 따른다. `/blog-write` 스킬도 글 종류를 정한 뒤 이 구역을 따른다.
- 보호 테스트 허용 목록에 `update_writing_guide` 한 줄(#185, 사용자 승인 2026-09-28). 발행 불가는 그대로.

## Impact

- 새 의존성 없음. REST 설정 API · 문서 스키마 그대로.
- 하지 않는 것: 가이드 부분 고치기(구역 단위), 가이드 충돌 검사(revision) — 사용자 한 명이라 마지막 저장이 이긴다. 기본 틀 내용 채우기(사용자가 말로 채운다).
