# mcp-preview (이슈 #139)

## Why

디자인은 눈으로 봐야 한다. AI가 스티커 겹침이나 어색한 글꼴을 스스로 고치려면 실제 블로그 모양 화면을 봐야 한다. Claude Code 등 MCP 클라이언트는 이미지를 읽을 수 있다.

## What Changes

- MCP 도구 `preview_post({ slug, part? })`(읽기 전용): 초안을 공개 렌더와 같은 HTML · CSS로 데스크톱(1280) · 모바일(390) 폭에서 찍어 JPEG 두 장을 돌려준다. 한 장의 긴 변은 1568px 이하, 페이지가 길면 구간으로 나눠 `part`(1부터)로 받고, 응답 글에 전체 구간 수를 적는다.
- 브라우저는 로컬 설치본(e2e와 같은 Chromium)을 쓴다. 없으면 설치 명령을 알려 주는 도구 오류.
- `playwright-core`를 api 런타임 의존성으로(ADR-042, 사용자 승인). 보호 테스트 허용 목록 · annotations에 한 줄(adr-040).
- 형식 가이드 · `/blog-write` 스킬: 꾸민 뒤 `preview_post`로 보고 겹침 · 글꼴을 스스로 고친다.

## Impact

- 새 의존성 1(전이 0). 문서 스키마 · REST 계약 그대로.
- 하지 않는 것: 배포(Lambda)에서 찍기(M4 후속), 편집 화면용 미리보기 이미지.
