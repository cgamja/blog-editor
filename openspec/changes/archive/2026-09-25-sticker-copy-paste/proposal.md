# sticker-copy-paste (이슈 #65)

## Why

ProseMirror는 클립보드에 조각을 HTML로만 싣고(`data-pm-slice`에는 열린 깊이 · 조상만), 붙여넣기 정규화(editor-paste)는 스티커를 늘 지운다. 그래서 에디터 안에서 스티커 있는 블록을 복사 · 붙여넣기하거나 잘라 옮기면 스티커가 사라진다. 스티커가 화면에 보이게 되면서 사용자 눈에도 없어진다.

## What Changes

- editor-core 새 플러그인 `stickerClipboard(schema)`: 복사할 때(`transformCopied`) 최상위 블록의 스티커를 탭 메모리에 두고, `clipboardSerializer`가 클립보드 HTML 첫 블록에 추측할 수 없는 표식을 단다. 붙여넣을 때(`transformPastedHTML` → `transformPasted`) 표식이 메모리에 있고 조각 모양이 같으면 스티커를 되살린다
- 블록 글자 전체를 고른 열린 끝 블록(세 번 클릭 · 끌기)은 빈 최상위 글자 블록(글자 · 스티커 없음)에 붙일 때만 조각 양끝을 닫아 되살리고, 커서는 붙인 글자 끝에 둔다
- 글 하나 스티커 상한을 넘으면 붙인 쪽 스티커를 뒤에서부터 뺀다(결과 문서로 센다 — 잘라내기 이동은 걸리지 않는다)
- editor-core `closed-values`: 스티커 하나를 거르는 `stickerOrNull` — 꾸미기 커맨드(`addSticker`)와 같이 쓴다
- adr-027: 클립보드 HTML은 믿지 않고 탭 메모리 + 표식으로 되살린다

## Impact

- 외부 HTML(다른 앱 · 다른 탭 · 표식을 흉내 낸 속성)은 지금처럼 스티커가 없다 — 붙여넣기 정규화는 그대로다
- 메모리는 탭(모듈) 하나를 에디터들이 같이 쓴다 — 같은 탭이면 다른 글로 복사해도 남는다. 새로 고치면 사라진다
- 하지 않는 것: 다른 탭 · 다른 앱으로 스티커 옮기기 · 블록 글자 일부만 고른 열린 끝 블록 · 남의 글자 가운데에 섞이는 열린 끝 블록의 스티커 · 에디터 안 끌어 복사(Alt 끌기 — 내부 조각이 표식 없이 온다) · 사용자에게 뺀 스티커 수 알리기
