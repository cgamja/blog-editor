## MODIFIED Requirements

### Requirement: 정의 밖 markdown은 거부한다

변환은 SHALL 다음을 변환하지 않고 거부한다.

- `#` h1 · h4 이하 · 각주 · 글이 없는 할 일 항목(`- [ ]`)
- 쓰이지 않는 링크 참조 정의(`[r]: url`)
- 인라인/블록 HTML(`<div>` · `<br>` · `<u>` 포함)
- 절대 URL 이미지
- 인용 안의 제목 · 목록 안의 코드 블록
- 문단 하나 + 안쪽 목록 모양이 아닌 목록 항목(문단 둘 · 안쪽 목록 뒤 문단 · 문단 없이 시작)

쓰인 참조 링크(`[글][r]` + `[r]: url`)는 인라인 링크와 같은 doc가 되므로 받는다. 링크 문법이 보이면(참조 링크 포함) 파서 필터와 무관하게 href를 `hrefSchema`로 검사해 거부한다. `javascript:` 링크를 글자로 조용히 남기지 않기 위해서다. 받은 글자 · 링크가 결과에서 조용히 사라지면 안 된다. 그래서 결과 doc에 자리가 없는 입력은 성공으로 돌려주지 않고 거부한다.

#### Scenario: 정의 밖 markdown은 거부한다

- **WHEN** 다음 열두 가지를 각각 넣는다
  - `# 제목` · `<u>밑줄</u>` · `<div>` · `<br>`
  - `![x](https://a.com/x.png)` · `[x](javascript:alert(1))`
  - 인용 안의 `## 제목` · 목록 항목 안의 ``` 펜스
  - 각주(`글[^1]` · 빈 줄 · `[^1]: 설명`) · 글이 없는 할 일 항목(`- [ ]`)
  - 쓰이지 않는 링크 참조 정의(`글` · 빈 줄 · `[r]: https://a.com`)
  - 목록 항목 안 두 번째 문단(`- a` · 빈 줄 · `  b`)
- **THEN** 열두 경우 모두 변환이 실패하고 markdown-validation-message 형식의 메시지가 나온다

## ADDED Requirements

### Requirement: 할 일 목록은 목록 항목의 체크 여부가 된다

변환은 SHALL 목록 항목 첫 줄 맨 앞의 `[ ]` · `[x]` · `[X]`와 그 뒤 공백 하나 이상, 그리고 글을 할 일 항목으로 읽는다(adr-028 3절 · adr-036). 표지와 공백은 글에서 빠지고 항목의 `attrs.checked`가 된다(`[ ]` → `false`, `[x]` · `[X]` → `true`).

- 점 목록 · 번호 목록 · 안쪽 목록 어디서나 읽는다. 한 목록 안에 할 일 항목과 보통 항목이 섞여도 된다.
- 표지는 markdown 원문으로 판정한다. 그래서 `\[ ] 글`처럼 대괄호를 이스케이프하면 보통 항목의 글자 `[ ] 글`로 남는다.
- 표지 뒤에 글이 없는 항목(`- [ ]`)은 거부한다. 빈 할 일 항목은 markdown으로 나를 수 없다(빈 항목은 직렬화에서 빠진다).
  표지 뒤 원래 글이 `[ ]` · `[x]`인 항목(`- [ ] [ ]`)은 빈 할 일이 아니라 글이 `[ ]`인 할 일이다.
- 목록 밖 문단의 `[ ] 글`은 그냥 글자다.

#### Scenario: 할 일 항목을 읽는다

- **WHEN** `- [ ] 할 일` · `- [x] **끝** 남` · `- 보통` 세 항목 점 목록과, `1. [X] 둘` 아래 안쪽 `- [ ] 안쪽`이 든 번호 목록을 변환한다
- **THEN** 점 목록 항목의 `checked`는 차례로 `false` · `true` · 없음이고 글은 `할 일` · `끝`(bold) + ` 남` · `보통`이다. 번호 목록 항목은 `checked: true`(글 `둘`), 안쪽 항목은 `checked: false`(글 `안쪽`)다

#### Scenario: 이스케이프한 대괄호는 글자다

- **WHEN** `- \[ ] 글자`를 변환한다
- **THEN** 성공하고 항목에 `checked`가 없으며 글이 `[ ] 글자`다

#### Scenario: 글이 대괄호뿐인 할 일 항목

- **WHEN** `- [ ] [ ]`와 `- [x] [x]`를 각각 변환한다
- **THEN** 성공하고 앞 표지는 `checked`(`false` · `true`), 뒤 `[ ]` · `[x]`는 항목 글이다

#### Scenario: 글이 없는 할 일 항목은 거부한다

- **WHEN** `- [ ]`와 `- [x]`를 각각 변환한다
- **THEN** 두 경우 모두 실패하고 메시지가 `블록 1 (1줄): 할 일 항목에는 글이 있어야 한다(받음: "[ ]") → - [ ] 할 일` 모양이다
