# block-spacing (이슈 #140)

## Why

사용자는 AI로 고칠 때 "여기 간격을 이렇게 해줘"처럼 블록 사이 여백을 말로 바꾸길 원한다(2026-09-25, 간격 꾸밈을 넣기로 결정). 지금 간격은 꾸밈 목록에 없다. 본문 리듬(문단 1.1em · 제목 2.2em 등)이 고정이라, 사진 앞뒤를 띄우거나 이어지는 두 문단을 붙일 방법이 없다. 임의 px는 닫힌 집합 밖이라 받지 않는다(adr-008). 그래서 단계로만 둔다.

## What Changes

- content-schema
  - 사진 자리를 뺀 모든 최상위 블록 attrs에 `space`를 더한다. 값은 `sm` · `lg` · `xl`(좁게 · 넓게 · 아주 넓게)이다.
  - 값이 없으면 "보통"이다. 기본 본문 리듬을 그대로 쓴다.
  - 뜻은 **블록 위 여백**(앞 블록과의 간격)이다. 글 첫 블록에서는 보이는 차이가 없다.
  - 안쪽 노드에는 자리가 없다(꾸미기는 최상위에만).
  - schemaVersion은 1 그대로다(추가뿐, adr-020 선례).
- content-convert
  - 지시어 키 `space`를 더한다(`{space=lg}`). 사진 자리를 뺀 모든 최상위 블록에 쓸 수 있다.
  - 직렬화 순서는 기존 키 뒤다.
  - 형식 가이드 표 · MCP `update_draft` 설명에 옮긴다.
- content-render
  - 꾸밈 래퍼 `div.post-block`에 `data-space`로 낸다.
  - post.css가 단계마다 여백을 `em`으로 정한다. 본문 리듬과 같은 단위다.
  - 미리보기와 공개 HTML이 같은 CSS를 쓴다.
- editor-core
  - 최상위 블록 노드에 `space` 속성을 둔다.
  - DOM(`data-space`)을 읽고 쓴다.
  - `setBlockSpace` 커맨드를 둔다.
  - 붙여넣기 정규화는 안쪽 자리면 지운다.
  - 나누기(Enter) · 붙여넣기로 나누기 · 목록 빼내기는 간격을 한 조각(앞 조각)에만 남기고, 목록이 통째로 빠지면 빠져나온 블록이 잇는다.
  - 감싸기(목록 · 인용 · 콜아웃)는 간격을 바깥 블록으로 옮기고 안쪽 정렬을 지운다 — 정렬 문단을 감싸면 안쪽에 정렬 자리가 없어 blockGuard가 거부하던 기존 버그 수정이다.
- editor-react
  - 꾸미기 패널에 「간격」 필드를 둔다(보통 · 좁게 · 넓게 · 아주 넓게).

## Impact

- 새 의존성 없음.
- 사이트 레포 sanitizer가 `data-space`를 받아야 공개 글에 간격이 보인다. 사이트 레포 후속이다.
- 하지 않는 것: 줄 간격(line-height), 블록 아래 여백, px 값, 안쪽 블록 간격.
