# editor-live-reflect (이슈 #142 앞쪽)

## Why

에디터를 열어 둔 채 AI가 MCP로 초안을 고치면 에디터에 보이지 않고, 사람이 저장하면 409 충돌이 난다. 글은 AI가 쓰고 고치는 게 기본이라(2026-09-25 사용자 방향) 사람이 에디터로 지켜보는 흐름이 자주 생긴다.

## What Changes

- 편집 화면은 탭이 보이는 동안 짧은 간격으로(그리고 창에 돌아올 때) 서버 revision을 확인한다.
- 새 revision이고 저장 안 한 고침이 없으면 문서를 바꿔 끼우고, 바뀐 최상위 블록을 잠깐 칠한다.
- 저장 안 한 고침이 있으면 "AI가 고쳤어요" 띠에 「불러오기」를 띄운다. 불러오면 지금 고친 내용은 버린다(띠에 적는다).
- 한글 조합 중에는 바꿔 끼우지 않고 조합이 끝난 뒤로 미룬다.
- 자기 저장으로 바뀐 revision은 새 revision으로 보지 않는다.

## Impact

- 새 의존성 없음(웹소켓 · SSE 없이 기존 `GET /api/posts/:slug`). API 그대로.
- 하지 않는 것: AI 수정 되돌리기(#186), 두 판 합치기.
