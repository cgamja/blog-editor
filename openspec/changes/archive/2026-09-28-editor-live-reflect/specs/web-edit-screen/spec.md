## ADDED Requirements

### Requirement: 열린 편집 화면은 다른 곳에서 바뀐 초안을 알아챈다

편집 화면은 SHALL 탭이 보이는 동안 주기적으로, 그리고 창에 돌아올 때 서버의 글 revision을 확인한다. 자기 저장이 아닌 새 revision이면:

- 저장 안 한 고침이 없으면 문서 · 글 정보를 새 판으로 바꿔 끼우고, 바뀐 최상위 블록을 잠깐 옅게 칠한다
- 저장 안 한 고침이 있으면 "AI가 고쳤어요" 띠와 「불러오기」를 보인다. 띠는 불러오면 지금 고친 내용이 사라진다고 알린다. 「불러오기」는 새 판으로 바꿔 끼운다
- 한글 조합 중이면 바꿔 끼우지 않고, 조합이 끝난 뒤 다시 판단한다

#### Scenario: 손대지 않은 편집 화면은 새 판으로 바뀐다

- **WHEN** 편집 화면을 연 채 다른 곳(API)에서 그 초안의 둘째 문단을 고친다
- **THEN** 편집 화면 본문이 새 글로 바뀌고 둘째 문단이 잠깐 칠해지며, 이어서 저장해도 충돌이 나지 않는다

#### Scenario: 고치던 중이면 띠가 뜨고 불러오기로 바뀐다

- **WHEN** 본문에 글자를 쳐서 저장 안 한 고침이 있는 채 다른 곳에서 초안을 고친다
- **THEN** 본문은 그대로이고 "AI가 고쳤어요" 띠가 보이며, 「불러오기」를 누르면 새 글로 바뀐다

#### Scenario: 자기 저장은 새 판으로 보지 않는다

- **WHEN** 편집 화면에서 고치고 저장한다
- **THEN** 띠가 뜨지 않고 칠하기도 없다
