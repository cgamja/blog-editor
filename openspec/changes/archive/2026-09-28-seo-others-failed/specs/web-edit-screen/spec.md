# web-edit-screen — delta

## MODIFIED Requirements

### Requirement: 발행 확인은 검색 노출 점검을 보여 주고 막지는 않는다

편집 화면의 발행 확인 대화상자는 SHALL 지금 문서 · 글 정보 · 다른 글 제목으로 `checkSeo`를 돌린 결과를 "검색 노출 점검" 목록으로 보여 준다.

- 점검 제목 아래에 `scoreSeo` 점수를 "검색 노출 점수 N점"으로 보인다. 문서를 읽지 못했으면 점수를 보이지 않는다
- 등급이 must인 발견이 있으면 목록 위에 그 사실을 한 줄로 알린다
- 발행 버튼은 그대로 누를 수 있다(점검은 발행을 막지 않는다)
- 발견이 없으면 "점검할 것이 없어요"를, 문서를 읽지 못했으면(닫힌 집합 위반) "점검할 수 없어요"를 보인다
- 다른 글 목록(`GET /api/posts`)을 읽지 못했고 캐시된 성공 데이터도 없으면 점수 · 목록 대신 "다른 글 목록을 읽지 못해 제목 · 설명 중복을 점검할 수 없어요."와 「다시 시도」를 보인다. 「다시 시도」는 목록을 다시 읽는다. 「다시 시도」로 다시 읽는 중에도 이 안내를 유지하고 점수를 보이지 않는다. 캐시된 성공 데이터가 있으면 그것으로 점검한다
- 다른 글 목록을 처음 읽는 중이면(캐시된 데이터도 실패도 없으면) 점수 · 목록 대신 "다른 글과 겹치는지 확인하는 중이에요."를 보인다 — 중복 비교 없는 점수를 보이지 않는다
- 다른 글은 `GET /api/posts` 요약을 `seoOthersOf`로 바꿔 넘긴다 — 설명 중복까지 점검해 MCP 점수와 같다
- 자기 글(지금 주소 · 불러온 주소 · 서버에 저장된 주소)은 제목 · 설명 중복 비교에서 뺀다

「글 정보」 탭에는 핵심 검색어(`keyword`) 칸이 있다. 공백만 남기면 저장하는 글 정보에서 칸이 빠진다(`withMetaPatch`).

#### Scenario: alt 없는 이미지가 있으면 발행 확인에 must가 보이고 발행은 된다

- **WHEN** 제목 · 설명 · 카테고리를 채우고 alt 없는 이미지가 든 글에서 발행을 누른다
- **THEN** 대화상자에 점검 목록 · 이미지 설명 항목 · 100보다 작은 검색 노출 점수가 보이고, 발행 버튼을 누르면 발행된다

#### Scenario: 글 목록을 읽지 못하면 점수 대신 점검 불가 안내와 다시 시도가 보인다

- **WHEN** 글 목록 요청이 재시도까지 모두 실패한 채 발행 확인을 연다
- **THEN** 검색 노출 점수와 점검 목록이 없고, 점검 불가 안내와 「다시 시도」 버튼이 보이며 발행 버튼은 그대로 있다

#### Scenario: 다시 시도로 목록을 다시 읽는 중에도 점수가 보이지 않는다

- **WHEN** 글 목록 실패로 점검 불가 안내가 보인 뒤, 목록이 여전히 실패하는 채로 「다시 시도」를 누른다
- **THEN** 다시 읽는 동안에도 검색 노출 점수가 보이지 않는다

#### Scenario: 글 목록 응답이 오기 전에 발행 확인을 열면 점수가 보이지 않는다

- **WHEN** 글 목록 응답이 아직 오지 않은 채 발행 확인을 연다
- **THEN** 검색 노출 점수가 보이지 않는다
