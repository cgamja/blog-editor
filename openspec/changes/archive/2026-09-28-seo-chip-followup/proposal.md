# seo-chip-followup (이슈 #176)

## Why

#151 에디터 SEO 칩 재검사 · CodeRabbit에서 남은 것들이다. 점이 사라질 때 강조 상태가 남아, 포인터가 없는데도 블록이 계속 칠해진다. 크기를 모르던 그림이 로드되며 높이가 바뀌어도 점이 옛 자리에 남는다. 폭을 줄인 그림의 점은 본문 칸 안에 서서 다른 점과 줄이 맞지 않는다. 스펙 시나리오 몇 개는 테스트로 고정돼 있지 않다.

## What Changes

- editor-react `BlockFlagLayer`: 점 목록이 비거나 강조 중인 블록이 목록에 없으면 강조를 지운다.
- `useBlockFlagRows`: 편집 영역 안 그림이 로드되거나 내용 크기가 바뀌면 점 위치를 다시 잰다.
- 점 가로 위치를 본문 칸 오른쪽으로 통일한다(폭 줄인 그림도 같은 세로줄) — 사용자 결정 2026-09-28.
- 테스트 보강: stale 동안 점 · 블록 항목, 호버 강조 e2e, `selectBlock` 경계.

## Impact

- 새 의존성 없음. 문서 · API 그대로.
- 하지 않는 것: 점 모양 · 색 변경, 640px 미만 표시.
