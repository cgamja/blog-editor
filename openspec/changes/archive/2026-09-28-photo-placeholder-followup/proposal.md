# photo-placeholder-followup (이슈 #172)

## Why

#136(사진 자리) 리뷰에서 남긴 세 가지다. 사진 자리에 놓은 파일이 업로드에 실패한 뒤 「다시 시도」하면 채우기가 풀려, 그림이 사진 자리 앞에 새로 들어가고 사진 자리 · 설명이 남는다. AI의 여러 블록 바꾸기가 사진 설명(brief)이 있는 그림을 덮으면 설명이 알림 없이 사라진다. 문서 끝 자리에서 기다리던 업로드는 바로 앞 블록이 채우기 · 되돌리기로 바뀌기만 해도 버려진다.

## What Changes

- 다시 시도는 처음 올리기의 채우기 대상(사진 자리)을 잇는다.
- content-convert `editDocRange`: 여러 블록 바꾸기가 brief 있는 그림을 덮으면, 새 markdown에 같은 src 그림이 있을 때 brief를 옮기고 없으면 실패로 알린다(사용자 결정 2026-09-28). 빈 markdown 지우기는 막지 않는다. 형식 가이드 · MCP 설명 한 줄. ADR-039(ADR-033 보강).
- 문서 끝 자리 업로드는 문서를 통째로 바꾼 경우에만 버린다(사용자 결정 2026-09-28).

## Impact

- 새 의존성 없음. 문서 스키마 · 공개 계약 그대로.
- 하지 않는 것: 지우기에서 brief 보존, 그림 하나 → 하나 교체 경로(그림엔 집을 글이 없다).
