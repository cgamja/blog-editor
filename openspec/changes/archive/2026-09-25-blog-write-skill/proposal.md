# blog-write-skill (이슈 #141)

## Why

사용자는 에디터 사용법을 익히지 않고, 이 레포의 Claude Code에서 블로그 글을 자동으로 쓰길 원한다(2026-09-25, M7 AI 블로그 자동화). 사람이 할 일은 세 번이다. ① 주제를 준다. ② 방향을 확인한다. ③ 미리보기를 보고 발행한다. 글 종류(앱 소개 · 정보 전달 · 육아 이야기 등)가 다양해서, 다 쓰고 뒤집기보다 목차 단계에서 한 번 멈추는 A안을 사용자가 골랐다.

## What Changes

- 레포 스킬 `.claude/skills/blog-write/SKILL.md`를 추가한다. `/blog-write <주제>` 한 명령으로 아래 순서를 돈다.
  1. 준비: MCP 연결을 확인하고 `get_writing_guide`를 읽는다.
  2. 글 종류를 정한다.
  3. 출처가 있는 리서치를 한다.
  4. **방향 확인에서 멈춘다.** 제목 후보 3개 · 목차 · 핵심 검색어 · 카테고리 · 주소를 보여 준다.
  5. 본문과 꾸밈을 쓴다.
  6. `check_draft` → `create_draft` → 오류를 보고 스스로 고친다.
  7. 원하면 claude-seo로 평가한다.
  8. 에디터 링크와 사진이 필요한 자리 목록을 보고한다.
- 지금 있는 MCP 도구 6개로 돈다. 아직 없는 기능은 "도구가 생기면"으로 갈라 둔다(keyword 인자 #138, 부분 고치기 #135, 사진 자리 #136, 스티커 마크다운 #134, 미리보기 이미지 #139, AI 이미지 #137).
- 스킬 안 마크다운 예시가 형식 검사(`convertMarkdown`, `check_draft`와 같은 검사)를 통과하는지 테스트로 고정한다. AI가 예시를 그대로 따라 써도 저장이 거부되지 않게 하기 위해서다.

## Impact

- 발행 도구는 없다(adr-007). 스킬은 초안까지만 쓰고, 발행은 사람이 에디터에서 한다.
- AI 이미지 생성 단계는 넣지 않는다. 결정 뒤 추가한다(#137).
- 코드 경로는 바뀌지 않는다. 테스트 하나가 레포 루트의 스킬 파일을 읽는다.
- 1단계 본인용 보조 층이다. adr-007이 버린 대안(CLI를 전용 챗봇으로 만들기)을 뒤집지 않는다. MCP 도구와 "초안만" 원칙은 그대로다. 받아들인 비용: 커넥터로 쓰는 사람(claude.ai · ChatGPT)은 이 흐름을 받지 못한다. 필요해지면 흐름을 글쓰기 가이드(`get_writing_guide`) 쪽으로 옮긴다.
