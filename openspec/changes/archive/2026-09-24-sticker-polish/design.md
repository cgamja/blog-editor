# sticker-polish — 설계

## 1. 재현 (고치기 전)

headless shell + CDP, 플레이그라운드 allBlocks. 문단 0에 패널로 하트를 붙이고(기본 15%) 다섯 자리로 끌어 놓았다. 증거는 `.claude/state/evidence/71-sticker-polish/before-*`.

| 자리                                                    | 결과                                       |
| ------------------------------------------------------- | ------------------------------------------ |
| 같은 문단 안 · 문단 틈 · 제목 위 60px · 종이 왼쪽 200px | 옮겨짐. 틈에서는 유령이 포인터에서 14px 튐 |
| 마지막 블록 아래 80px                                   | 문서 그대로                                |

끄는 동안 찍은 화면에서 원래 하트가 제자리에 그대로 보이고, 반투명 유령과 「제목에 붙어 있어요」 꼬리표가 따로 떠 있었다. 스티커 버튼이 128×128px라 글자 위를 크게 덮었다.

## 2. 놓을 자리 — 한도 없는 스냅

`placeStickerNear`는 블록마다 허용 사각형 안으로 점을 옮기고(스냅) 스냅 거리가 가장 짧은 블록을 고른다. 24px 한도를 없앴다. 돌려주는 좌표는 허용 사각형 안의 점이라 범위 밖 값이 생기지 않는다(자르는 것이 아니라 허용 안에서 가장 가까운 점을 고르는 것). null은 스티커 크기가 범위(5~50%) 안인 블록이 하나도 없을 때뿐이다.

유령은 지금처럼 놓일 자리에 그린다. 허용 안이면 포인터를 그대로 따라오고, 밖이면 가장 가까운 허용 끝에 붙어 보인다 — 놓은 뒤 튀지 않는다.

## 3. 원래 스티커 숨기기 — 노드 장식

스티커 img는 ProseMirror가 그린 DOM이다. 거기에 style을 직접 넣으면 DOMObserver가 바뀐 DOM을 다시 읽는다. 공식 경로는 노드 장식이다(https://prosemirror.net/docs/ref/#view.Decoration^node — 움직임 미리 보기와 같은 방식).

- `stickerHiding()` 플러그인 상태 = 숨긴 `StickerRef | null`. 메타로 바꾸고, `docChanged`면 null로 돌아간다(놓기 트랜잭션이 곧 해제다).
- 장식은 그 최상위 블록에 `data-sticker-hidden="<순번>"`을 단다. 어느 img를 가릴지는 CSS가 고른다: `[data-sticker-hidden="N"] > :nth-child(N+1 of .post-sticker)`. 순번이 글마다 달라 정적 CSS 12줄 대신 StickerLayer가 지금 순번 하나만 `<style>`로 그린다(`hiddenStickerRule`).
- 메타만 있는 트랜잭션은 스텝이 없어 되돌리기 기록에 남지 않는다(prosemirror-history는 스텝 0개면 건너뛴다).
- 끄기를 시작할 때 숨기고, 끝나거나 취소되면 푼다. 크기 · 회전 끌기도 유령이 대신 보이므로 같이 숨긴다.

## 4. 커서

- 네 모서리 조절점은 테두리와 함께 돈다. 화면 각도 = 모서리 기본 각도(se 45° · sw 135° · nw 225° · ne 315°, y 아래) + 회전. 180°로 접어 가장 가까운 CSS 크기 커서를 고른다(`resizeCursor`).
- 회전 손잡이는 회전 화살표 SVG 커서(data URI, 시스템 커서처럼 검은 선 + 흰 테두리)와 대체값 `grab`. 커서 이미지 안의 색은 CSS 변수를 못 쓰므로 토큰이 아니라 시스템 커서 관례를 따른다.
- 옮기기 버튼은 `grab`, 끄는 중(포인터를 잡은 버튼)은 `grabbing`.
- 지우기(×)는 오른쪽 위 모서리 자리를 조절점에 내주고, 회전 손잡이 오른쪽으로 옮긴다.

## 5. 크기

- 커맨드 기본 크기 15 → 8(플레이그라운드 본문 약 850px에서 68px, 디자인 종이 글 폭 600px에서 48px).
- 패널에서 끌어 올 때 88px → 48px. 블록 폭이 960px을 넘으면 48px가 5% 밑이라 그 블록을 건너뛴다 — 지금 본문 폭에서는 해당 없음.
