# editor-ordered-list-input-rule Specification

## Purpose

에디터에서 `n. `을 쳐서 n부터 시작하는 번호 목록을 바로 만든다(이슈 #115). 시작 번호의 저장 · DOM · 목록 갈림은 editor-ordered-list-start가 맡는다.

## Requirements

### Requirement: 입력 규칙 n. 은 n부터 시작하는 번호 목록을 만든다

editor-core 입력 규칙은 SHALL 최상위 문단 맨 앞에서 `n. `(n은 1~3자리이면서 `ORDERED_LIST_START_RANGE` 안의 정수)을 입력하면 그 문단을 번호 목록의 첫 항목으로 바꾸고 start를 n으로 둔다(1이면 start가 없다). `0. `과 네 자리 이상 번호는 글자로 남는다 — 한국어 날짜(`2025. 9. 25.`)가 목록이 되지 않게 하려는 것이고, 큰 번호는 가져오기 · 붙여넣기로 들어온다. 바로 앞 블록이 번호 목록이고 그 목록의 시작 번호 + 항목 수가 n이면 그 목록의 마지막 항목으로 합친다. 단 새 목록이 꾸미기(글꼴 · 움직임 · 스티커)를 가지면 합치지 않는다. 표시 글자는 문서에 남지 않고 결과는 저장 형식으로 읽힌다.

#### Scenario: 빈 문단에 3. 입력

- **WHEN** 빈 최상위 문단에서 `3. `을 입력한다
- **THEN** start 3 번호 목록의 첫 항목 문단이 되고 표시 글자는 없다

#### Scenario: 범위 밖 번호

- **WHEN** 빈 최상위 문단에서 `0. `이나 10자리 번호 뒤 `. `을 입력한다
- **THEN** 규칙이 처리하지 않고 글자가 그대로 남는다

#### Scenario: 날짜는 목록이 되지 않는다

- **WHEN** 문단 맨 앞에서 `2025. `를 입력한다
- **THEN** 글자로 남고 번호 목록이 되지 않는다

#### Scenario: 앞 번호 목록에 이어지는 번호

- **WHEN** 항목 둘인 번호 목록 바로 뒤 빈 문단에서 `3. `을 입력한다
- **THEN** 앞 목록의 셋째 항목이 되고 번호 목록은 하나다

#### Scenario: 3부터인 앞 목록에 이어지는 번호

- **WHEN** start 3 목록(가 · 나) 바로 뒤 빈 문단에서 `5. `를 입력한다
- **THEN** 목록 하나에 항목 셋이고 start는 3이다

#### Scenario: 이어지지 않는 번호

- **WHEN** 항목 둘인 번호 목록 바로 뒤 빈 문단에서 `5. `를 입력한다
- **THEN** 앞 목록과 따로인 start 5 번호 목록이 된다

#### Scenario: 꾸미기가 있는 문단은 합치지 않는다

- **WHEN** 항목 둘인 번호 목록 바로 뒤, 스티커가 있는 빈 문단에서 `3. `을 입력한다
- **THEN** 스티커를 가진 start 3 번호 목록이 따로 생긴다

#### Scenario: 글꼴만 가진 문단도 합치지 않는다

- **WHEN** 항목 둘인 번호 목록 바로 뒤, 글꼴만 가진 빈 문단에서 `3. `을 입력한다
- **THEN** 그 글꼴을 가진 start 3 번호 목록이 따로 선다
