# web-edit-screen Specification

## Purpose

web 편집 화면(`/posts/new` · `/posts/:slug/edit`, 디자인 68:2 · 67:2) — 새 글 저장 · 발행, ⌘S, 409 충돌 대화상자, 세션 만료 띠. 실브라우저 시나리오(이슈 #97).

## Requirements

### Requirement: 편집 화면은 새 글을 저장하고 발행한다

web의 `/posts/new`는 SHALL 바로 편집 화면을 열고, 제목에서 제안한 주소로 첫 저장을 한 뒤 `/posts/<slug>/edit`로 주소만 바꾼다(에디터는 그대로). 발행은 확인 대화상자를 거쳐 `draft: false`로 저장하고 "빌드 중 — 1~2분 뒤 공개"를 보이며, 그 뒤 주소 칸은 잠긴다.

#### Scenario: 새 글 → 저장 → 발행 (실브라우저)

- **WHEN** 새 글에서 제목 · 설명 · 카테고리 · 본문을 쓰고 2초 기다린 뒤 「발행」 → 확인한다
- **THEN** 머리줄이 "초안 저장됨, …"을 거쳐 "빌드 중 — 1~2분 뒤 공개"이고, 주소가 `/posts/<slug>/edit`, 주소 칸이 잠기고, `GET /public/posts`에 그 글이 있다

### Requirement: 편집 화면은 ⌘S로 바로 저장하고, 409면 충돌 대화상자를 연다

web 편집 화면은 SHALL ⌘S · 「초안 저장」에서 기다리지 않고 저장하고, 409면 디자인 67:2의 세 선택지(복사해 두고 최신 열기 · 저장하지 않고 계속 · 덮어쓰기)를 연다.

#### Scenario: ⌘S (실브라우저)

- **WHEN** 불러온 글에서 한 글자 고치고 곧바로 ⌘S를 누른다
- **THEN** 2초를 기다리지 않고 "초안 저장됨, …"이다

#### Scenario: 두 탭 409 (실브라우저)

- **WHEN** 같은 글을 두 탭에서 열고 한 탭에서 저장한 뒤 다른 탭에서 고쳐 저장한다
- **THEN** 뒤 탭에 충돌 대화상자가 뜨고 「덮어쓰기」하면 "초안 저장됨, …"이다

### Requirement: 편집 화면은 세션이 끝나도 쓰던 글을 두고 떠나지 않는다

web 편집 화면은 SHALL 저장이 401이면 로그인 화면으로 곧장 보내지 않고 띠("로그인이 끝났어요 …" · 「다시 로그인」)를 보인다. 다시 로그인하면 같은 글로 돌아와 브라우저에 남은 글을 되살려 저장한다.

#### Scenario: 401 띠 → 다시 로그인 → 되살리기 (실브라우저)

- **WHEN** 편집 중 세션 쿠키를 지우고 고친 뒤, 띠의 「다시 로그인」으로 로그인한다
- **THEN** 같은 글 편집 화면이고 고친 내용이 남아 "초안 저장됨, …"이다

### Requirement: 발행 확인은 검색 노출 점검을 보여 주고 막지는 않는다

편집 화면의 발행 확인 대화상자는 SHALL 지금 문서 · 글 정보 · 다른 글 제목으로 `checkSeo`를 돌린 결과를 "검색 노출 점검" 목록으로 보여 준다.

- 점검 제목 아래에 `scoreSeo` 점수를 "검색 노출 점수 N점"으로 보인다. 문서를 읽지 못했으면 점수를 보이지 않는다
- 등급이 must인 발견이 있으면 목록 위에 그 사실을 한 줄로 알린다
- 발행 버튼은 그대로 누를 수 있다(점검은 발행을 막지 않는다)
- 발견이 없으면 "점검할 것이 없어요"를, 문서를 읽지 못했으면(닫힌 집합 위반) "점검할 수 없어요"를 보인다
- 다른 글은 `GET /api/posts` 요약을 `seoOthersOf`로 바꿔 넘긴다 — 설명 중복까지 점검해 MCP 점수와 같다
- 자기 글(지금 주소 · 불러온 주소 · 서버에 저장된 주소)은 제목 · 설명 중복 비교에서 뺀다

「글 정보」 탭에는 핵심 검색어(`keyword`) 칸이 있다. 공백만 남기면 저장하는 글 정보에서 칸이 빠진다(`withMetaPatch`).

#### Scenario: alt 없는 이미지가 있으면 발행 확인에 must가 보이고 발행은 된다

- **WHEN** 제목 · 설명 · 카테고리를 채우고 alt 없는 이미지가 든 글에서 발행을 누른다
- **THEN** 대화상자에 점검 목록 · 이미지 설명 항목 · 100보다 작은 검색 노출 점수가 보이고, 발행 버튼을 누르면 발행된다
