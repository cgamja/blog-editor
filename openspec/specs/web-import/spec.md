# web-import Specification

## Purpose

쓰던 마크다운을 초안으로 옮기는 대화상자(결정 A — 대화상자 한 장). 원문 | 미리보기를 보여 주고, 막는 메시지가 없고 메타가 저장 규칙에 맞을 때만 새 글로 저장한다(이슈 #98).

## Requirements

### Requirement: 가져오기는 미리보기가 통과한 것만 초안으로 만든다

가져오기 대화상자는 SHALL 붙여넣은 글이나 고른 `.md` 파일을 미리보기 API로 변환해 원문 | 미리보기로 보여 주고, 막는 메시지가 있거나 주소 · 제목 · 설명이 규칙에 맞지 않으면 「초안으로 만들기」를 끈다. 만들면 기존 저장 API에 `If-None-Match: *`로 초안(`draft: true` · `source: "editor"` · 오늘 날짜)을 저장하고 편집 화면으로 간다.

#### Scenario: 미리보기 결과와 입력으로 초안 파일을 만든다

- **WHEN** 변환된 doc과 제목 · 설명 · 카테고리 · 날짜로 초안 파일을 만든다
- **THEN** 현재 저장 형식 버전이고 `draft: true` · `source: "editor"`이며 그 doc · 메타를 담는다

#### Scenario: 영문 제목이면 주소를 제안하고 한글이면 비운다

- **WHEN** 제목 `Sleep Log: Week 1!`과 `수면 기록`으로 주소를 제안한다
- **THEN** 차례로 `sleep-log-week-1`과 빈 문자열이다

#### Scenario: 막는 메시지 · 틀린 주소면 만들 수 없다

- **WHEN** 미리보기가 실패했거나, 주소가 규칙에 맞지 않거나, 제목이 비었을 때 만들 수 있는지 묻는다
- **THEN** 모두 만들 수 없고, 성공한 미리보기와 맞는 입력이면 만들 수 있다

#### Scenario: 실브라우저 가져오기 (실브라우저)

- **WHEN** 로그인한 화면에서 가져오기 대화상자에 markdown을 붙여넣고 주소를 채워 초안으로 만든다
- **THEN** 미리보기가 공개 렌더러로 보이고, 표가 든 글은 줄 번호 메시지와 함께 버튼이 꺼지며, 맞는 글은 저장된 뒤 편집 경로로 간다

### Requirement: 가져올 파일은 마크다운 확장자와 크기 상한 안만 읽는다

가져오기는 SHALL 고른 파일이 `.md` · `.markdown`(대소문자 무시)이고 크기가 서버 markdown 상한의 4배 바이트(UTF-8 한 글자 최대 4바이트) 이하일 때만 읽는다. 아니면 읽지 않고 그 이유를 보여 준다.

#### Scenario: 확장자 · 크기로 파일을 거른다

- **WHEN** `note.MD`(작음), `note.txt`, 상한을 넘는 `big.md`를 거른다
- **THEN** 차례로 통과 · 확장자 문제 · 크기 문제다
