# ADR-011. WEB-SPEC 유틸리티 4종(es-toolkit · overlay-kit · use-funnel · suspensive)은 채택하지 않는다

- 날짜: 2026-09-22
- 상태: 승인됨
- 원천: cgamja develop-setup 스택 축 대조(플러그인 adr/0032) — SPEC 항목이 매니페스트에도 ADR에도 없으면 세팅이 끝나지 않는다

## 문제 (맥락)

WEB-SPEC은 유틸리티로 **es-toolkit**(lodash 대체) · **overlay-kit**(모달 상태) · **use-funnel**(다단계 플로우) · **suspensive**(Suspense 유틸)를 든다. 이 레포는 넷 다 쓰지 않는데, "안 쓰기로 했다"와 "아무도 안 정했다"는 다르다. 프레임워크(Next.js → Vite SPA)와 클라이언트 상태(Zustand 미사용)의 이탈은 adr-006에 있다.

## 결정

넷 다 **지금은 채택하지 않는다.** 필요가 생기면 LIBRARY 게이트(문제 한 문장 → 기존 스택으로 안 되는가 → 직접 구현이 더 싸지 않은가)를 거쳐 그때 ADR로 추가한다.

| 항목        | 안 쓰는 이유                                                                                                                                    |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| es-toolkit  | 순수 함수 층(스키마 · 변환 · 렌더)은 표준 라이브러리로 충분하고, 유틸 한 개를 위해 의존성을 들이지 않는다. 필요해지는 첫 함수에서 게이트를 연다 |
| overlay-kit | 화면이 넷(로그인 · 목록 · 편집 · AI 연결)이고 모달은 409 충돌 안내 정도. 지역 상태로 충분하다(adr-006 "그 밖의 클라이언트 상태")                |
| use-funnel  | 퍼널이 없다. SPEC도 "퍼널이 없는 프로젝트엔 불필요"라고 적었다                                                                                  |
| suspensive  | 서버 상태는 TanStack Query로 충분하고 Suspense 경계는 라우트 단위 몇 곳뿐이다. SPEC도 "Suspense 미사용 프로젝트엔 불필요"                       |

SPEC의 나머지 항목: TypeScript strict · React 19 · TailwindCSS 4 + cn · TanStack Query · Vitest · Playwright · MSW는 plan 02 · adr-006대로 해당 패키지가 생길 때 채택한다(지금은 web 패키지가 없어 매니페스트에 없다).

## 버린 대안

- **SPEC대로 전부 설치**: 쓰지 않는 의존성 넷. LIBRARY 게이트 1단계("문제로 시작하는가")를 통과하지 못한다.
- **기록 없이 두기**: 다음 세팅 · 리뷰가 매번 같은 질문을 한다.

## 감수한 트레이드오프

- 나중에 필요해지면 그때 게이트 + ADR 비용. 넷 다 도입이 국소적이라(유틸 함수 · 모달 · 퍼널 · Suspense 경계) 늦게 넣어도 되돌릴 게 없다.

## 재검토 조건

- web 패키지에서 같은 유틸을 두 번째로 손으로 짤 때(es-toolkit) · 모달이 3개를 넘을 때(overlay-kit) · 다단계 플로우가 생길 때(use-funnel).
