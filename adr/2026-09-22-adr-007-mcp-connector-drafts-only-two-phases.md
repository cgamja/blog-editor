# ADR-007. AI는 MCP 커넥터로 연결해 초안만 쓴다 — 서비스가 LLM을 호출하지 않는다. 본인용 1단계 뒤 외부 공개 2단계

- 날짜: 2026-09-22
- 상태: 승인됨
- 원천: 설계 문서 D9 · D13 · 3-12 MCP 커넥터 (2026-09-21 방향 전환)

## 문제 (맥락)

사용자는 이미 Claude · ChatGPT 구독이 있고 API 비용을 따로 내고 싶지 않다. 그런데 서비스가 사용자의 구독 OAuth 토큰으로 모델을 호출하는 것은 Anthropic이 2026-02에 금지했고(검색 요약 기준 — 2단계 공개 전 약관 원문 확인), 「Sign in with ChatGPT」도 Codex 도구 안에서만 동작한다. AI 비용 0원으로 AI가 글을 쓰게 할 길이 있는가. 그리고 이 도구를 외부 사용자에게도 열 것인가.

## 결정

- 방향을 뒤집는다: 서비스가 AI를 부르는 게 아니라 **AI(채팅 앱)가 서비스를 부른다.** 에디터 서버가 **MCP 서버**(`/mcp`)를 노출하고, 사용자가 claude.ai · ChatGPT에 커넥터로 연결한다. AI 호출 비용은 사용자의 구독이 낸다 — 이것은 공식 기능이다.
- 도구 6개: `get_writing_guide` · `list_posts` · `get_post` · `check_draft` · `create_draft` · `update_draft`. **발행 도구는 없다.** AI는 markdown으로 쓰고 서버가 변환 · 검증한다. 검증 실패 메시지를 보고 AI가 스스로 고친다.
- 가이드는 둘: 형식 가이드(우리가 관리) + 글쓰기 가이드(사용자가 편집).
- 인증은 OAuth(채팅 앱) 또는 **연결용 토큰**(무인 자동화 — 남이 만든 스크립트가 `create_draft`나 `POST /api/posts`를 부른다). 둘 다 범위는 초안 읽기 · 쓰기뿐. 초안 출처는 `meta.source`에 기록한다.
- 「AI로 쓰기」 버튼은 `claude.ai/new?q=…` · `chatgpt.com/?q=…` 바로가기로 남긴다. 고도화는 2단계.
- **2단계**: 1단계는 본인용 단일 워크스페이스(계정 1개 시드, 가입 화면 없음). 2단계에 회원가입 · 워크스페이스 · 사이트 연결 · AI 이미지 생성 · 커넥터 디렉터리 등록. 1단계에서 미리 해 두는 것은 둘뿐 — 저장 경로 `workspaces/<id>/posts/<slug>.json`, 계정 테이블 구조.

## 버린 대안

- **서비스가 API 키로 LLM 호출**: 사용자마다 API 비용. 외부 사용자에게는 키를 받거나 우리가 대납해야 한다.
- **사용자 구독 OAuth로 서비스가 모델 호출**: 약관 위반(2026-02). 막힌 길.
- **CLI 도구(Claude Code · Codex)를 특화 챗봇으로**: 본인용이면 되지만 외부 사용자에게 CLI 설치를 요구할 수 없다(사용자가 「외부 사용자」로 바꾸면서 폐기).
- **1단계부터 외부 공개**: 가입 · 워크스페이스 · 권한 · 과금이 범위를 폭발시킨다. 한 달 써 본 뒤 범위를 정한다.

## 감수한 트레이드오프

- AI가 쓴 초안은 채팅 앱 안에서 만들어지므로 에디터 화면에서 AI 경험이 끊긴다(「AI로 쓰기」가 바로가기인 이유). 미리보기 카드(MCP Apps) 지원 범위는 미검증.
- MCP SDK · Lambda 전송 방식(Streamable HTTP) · OAuth 구현 범위(동적 클라이언트 등록)는 미검증 — M0 스파이크. 실패하면 1단계는 고정 토큰으로 연결하고 OAuth는 2단계.
- 채팅에서 만든 이미지를 커넥터로 넘기는 길이 아직 없다. 이미지는 1단계에서 사람이 올린다.
- 외부 자동화가 초안을 쏟아부을 수 있다 — 워크스페이스별 초안 개수 한도와 요청 횟수 제한.

## 재검토 조건

- Anthropic/OpenAI가 서드파티 서비스의 구독 인증을 공식으로 열 때.
- 2단계 범위를 정할 때(외부 사용자의 글이 어디로 나가는가 · 수익 모델).
