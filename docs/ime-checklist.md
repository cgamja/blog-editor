# 한글 입력(IME) · 에디터 동작 실브라우저 체크리스트

M2 완료 조건(plan 07 "한글 입력 수동 체크리스트 통과") · 이슈 #44 · 스파이크 #2(TipTap × React 19 한글). 자동 테스트(Vitest node)는 조합 입력 · 선택 표시 · 드래그를 볼 수 없어서 사람이 실브라우저에서 확인한다(`.claude/rules/editor.md`).

## 띄우는 법

```bash
PORT=5199 pnpm --filter @blog-editor/editor-react dev   # → http://127.0.0.1:5199
```

픽스처(`minimal` · `allBlocks` · `decorationMax`)를 고르고, 오른쪽 JSON이 "저장할 수 없는 문서"로 바뀌지 않는지 함께 본다.

## 체크리스트

결과 칸: ✅ 통과 · ❌ 실패(메모에 재현 절차) · — 해당 없음. 입력기는 macOS 기본 한글(두벌식).

| #   | 동작                                                                                     | 기대                                                          | Chrome | Safari | 메모 |
| --- | ---------------------------------------------------------------------------------------- | ------------------------------------------------------------- | ------ | ------ | ---- |
| 1   | 문단에서 "한글" 조합 중(마지막 글자 미확정) Enter                                        | 조합이 확정된 뒤 줄이 나뉜다. 글자가 두 번 들어가지 않는다    |        |        |      |
| 2   | 조합 중 Backspace                                                                        | 자모 단위로 지워진다. 블록이 합쳐지지 않는다                  |        |        |      |
| 3   | 문단 맨 앞에서 조합 시작 → 앞 블록 경계에서 Backspace                                    | 조합 중에는 블록이 합쳐지지 않는다                            |        |        |      |
| 4   | 콜아웃 · 앱 스크린샷 바로 뒤 문단 맨 앞에서 Backspace 두 번                              | 첫 번: 앞 블록이 선택되고 외곽선이 보인다. 두 번: 블록 삭제   |        |        |      |
| 5   | 스티커가 붙은 블록(decorationMax) 가운데 · 맨 앞 · 끝에서 Enter(조합 중 포함)            | 스티커가 복제되지 않는다. JSON이 저장 가능 상태로 남는다      |        |        |      |
| 6   | 구글 독스에서 서식 있는 글(굵게 · 링크 · 제목 · 표) 복사 → 붙여넣기                      | 굵게 · 링크 · 제목만 남고 표 · 스타일 span은 사라진다         |        |        |      |
| 7   | 워드에서 복사 → 붙여넣기                                                                 | 6과 같다                                                      |        |        |      |
| 8   | `javascript:` 링크 · 외부 이미지가 든 HTML 붙여넣기                                      | 링크 마크 · 이미지가 들어오지 않는다                          |        |        |      |
| 9   | 블록을 드래그로 옮기기(스티커 블록 포함)                                                 | 스티커가 유지된다. 인용 안에 떨어뜨리면 거부(문서 그대로)     |        |        |      |
| 10  | Mod-Shift-↑/↓(블록 옮기기) · 맨 위/아래에서 누르기 · 조합 중 누르기                      | 옮겨진다. 양 끝에서 선택이 넓어지지 않는다                    |        |        |      |
| 11  | 툴바 "콜아웃 넣기" · "스크린샷 넣기" 뒤 바로 한글 입력                                   | 커서 자리에 입력된다(콜아웃 안 / 스크린샷 뒤 문단)            |        |        |      |
| 12  | 편집 중 커서 · undo를 만든 뒤 픽스처를 바꿨다 되돌리기, 스크린리더로 편집 영역 이름 듣기 | 픽스처가 바뀔 때만 새로 만든다. 편집 영역이 "본문"으로 불린다 |        |        |      |

## 기록

- 확인한 날짜 · 브라우저 버전 · OS를 적고, 실패 항목은 이슈로 연다.
- 라이브러리(TipTap · React · 브라우저)를 올릴 때마다 다시 돈다(adr-017 · adr-019).
