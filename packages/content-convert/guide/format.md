# 글 형식 가이드 (markdown 입력 문법)

`get_writing_guide`가 돌려주는 형식 가이드다. 문법마다 예시 하나. 스펙은 `openspec/specs/markdown-format` · `markdown-validation-message`.

**markdown은 원본이 아니라 입력이다.** 글의 원본은 서버가 저장하는 문서 JSON이고(adr-003), 너가 보낸 markdown은 변환 · 검증을 지나 그 JSON이 된다. 그래서 아래에 없는 문법은 "무시"가 아니라 "실패"다 — 실패 메시지를 보고 고쳐서 다시 보내면 된다. 제목 · 설명 · 카테고리 같은 메타는 markdown 안에 쓰지 않는다(도구 인자로 따로 준다).

## 1. 표준 문법 — 되는 것

| 쓰고 싶은 것 | 문법                              | 규칙                                                                   |
| ------------ | --------------------------------- | ---------------------------------------------------------------------- |
| 문단         | 빈 줄로 구분한 글                 |                                                                        |
| 제목         | `## 큰 제목` · `### 작은 제목`    | `#` 하나(h1)와 `####` 이하는 안 된다                                   |
| 목록         | `- 항목` · `1. 항목`              | 목록 안 목록은 된다. 항목 안에 문단 둘은 안 된다                       |
| 인용         | `> 글`                            | 인용 안에는 문단만                                                     |
| 코드         | ` ```ts ` … ` ``` `               | 언어는 소문자 · 숫자 · `+#.`만(`ts` `bash`)                            |
| 구분선       | `---`                             |                                                                        |
| 이미지       | `![대체 글자](/images/이름.webp)` | `/images/`로 시작하는 경로만. 절대 URL은 안 된다. 대체 글자 200자 이내 |
| 굵게         | `**글자**`                        |                                                                        |
| 기울임       | `*글자*`                          |                                                                        |
| 인라인 코드  | `` `글자` ``                      |                                                                        |
| 링크         | `[글자](https://…)`               | `http(s)://` · `mailto:` · `/`로 시작하는 내부 경로만                  |

예시 — 이것 하나가 위 표를 전부 쓴다:

````
## 육아비서 기록 기능

### 기록 종류

- 수유 · 수면 · 기저귀
  - 세부 항목은 *선택*이다
- `memo` 필드는 자유 글

1. 앱을 연다
2. 기록 버튼을 누른다

> 기록은 언제든 고칠 수 있다.

```ts
const record = { type: "feeding", at: Date.now() };
```

---

![기록 화면](/images/record-screen.webp)
````

### 안 되는 것 (변환 실패)

`# 제목`(h1) · `#### 제목` · 표(`| … |`) · 취소선(`~~`) · 각주 · 할 일 목록(`- [ ]`) · HTML(`<div>` · `<br>`) · 절대 URL 이미지 · `javascript:` 링크 · 인용 안의 제목 · 목록 안의 코드 블록.

## 2. 확장 문법 — 이 서비스에만 있는 것

### 콜아웃 `:::callout`

`tone`은 `note` · `tip` · `warning`. 생략하면 `note`. 안에는 문단과 목록만.

```
:::callout tone=tip
처음이라면 수유 기록부터 시작해 보세요.

- 하루 3번이면 충분하다
:::
```

> 이 컨테이너 문법은 스파이크 #2 결과에 따라 ````callout` 펜스 문법으로 바뀔 수 있다.

### 블록 속성 지시어 `{key=value}`

블록 **바로 앞 줄**(빈 줄 없이)에 한 줄. 그 블록 하나에만 적용되고, 글자로 남지 않는다.

| 키       | 값                                                           | 되는 블록            |
| -------- | ------------------------------------------------------------ | -------------------- |
| `font`   | `pretendard` · `jua` · `gaegu`                               | 글자가 있는 블록     |
| `motion` | `fade-in` · `fade-up` · `slide-left` · `slide-right` · `pop` | 모든 블록            |
| `width`  | `25`~`100`(%)                                                | 이미지 · 앱 스크린샷 |

```
{font=jua motion=fade-up}
## 베타 테스트를 시작합니다
```

### 앱 스크린샷 `{frame=app}`

이미지 앞에 `{frame=app}`를 두면 폰 프레임을 씌운 앱 스크린샷이 된다. 대체 글자가 캡션(120자 이내)이 된다. `width`와 같이 쓸 수 있다.

```
{frame=app width=60}
![오늘의 수유 기록 화면](/images/record-screen.webp)
```

### 스티커 — markdown 문법 없음

스티커는 사람이 에디터에서 끌어다 붙인다. `{stickers=…}`처럼 쓰면 실패한다. 정의 밖의 키(`color` 등)와 값(`font=comic`)도 실패다.

## 3. 검증 실패 메시지

실패하면 오류를 **전부 한 번에** 블록 순서대로 돌려준다. 한 줄 형식:

```
블록 <n> (<m>줄): <어긴 규칙(받은 값)> → <고친 예>
```

`<n>`은 최상위 블록 순번(1부터, 지시어 줄은 뒤 블록에 속한다), `<m>`은 markdown 줄 번호.

```
블록 3 (12줄): 제목은 ##·###만 쓴다(받음: "# 제목") → "## 제목"
블록 5 (20줄): 이미지는 /images/<이름>.<확장자> 경로만(받음: "https://cdn.example.com/a.png") → 사람이 에디터로 올린 경로 "/images/a.webp"
블록 7 (31줄): 링크는 http(s)·mailto·내부 경로만(받음: "javascript:alert(1)") → 링크를 지우거나 "https://…"
```

메시지대로 고쳐서 `check_draft`로 다시 검증하면 통과한 문서는 메시지가 비어 있다.
